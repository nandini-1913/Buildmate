# SCR-31 — Material calculator

- **Route:** `/material-calculator`.
- **Files:** `lib/features/catalog/presentation/screens/material_calculator_screen.dart` (115 lines); `lib/core/routes/app_routes.dart` (201); `lib/core/routes/app_router.dart` (300); `lib/core/state/cart_controller.dart` (158); `lib/features/catalog/domain/models/catalog_models.dart` (455).
- **Purpose:** Display current cart items and their estimated subtotal, or direct the user to the cart when it is empty; continue to quotation review.
- **Line-count convention:** physical source lines counted from the files listed above.

## Data

- Watches `CartController`; the displayed branch and values update when cart state changes (`material_calculator_screen.dart:13-15`).
- No API call or independent calculator state. Data comes from in-memory `CartController.items` (`cart_controller.dart:32-45`).
- Empty-cart action navigates to `AppRoutes.cart`; non-empty action navigates to `AppRoutes.quotationReview` (`material_calculator_screen.dart:49-52,106-111`; route constants `app_routes.dart:31,37`; route handling `app_router.dart:179-180,195-199`).
- This screen does not modify cart items or send a quotation payload itself. The Generate Quotation action only navigates to quotation review.

## States and messages

- **Empty:** centered calculator icon, `No materials selected`, explanatory sentence, and `Open Cart` button (`material_calculator_screen.dart:25-53`).
- **Non-empty:** current cart items, estimated total, construction-formula note, and `Generate Quotation` button (`material_calculator_screen.dart:54-112`).
- The two branches are selected solely by `CartController.isEmpty`; no separate loading, error, success, validation, or confirmation state is implemented (`material_calculator_screen.dart:13-15,25-26`; `cart_controller.dart:45`).
- If cart contents change while this route is visible, `context.watch<CartController>()` rebuilds it and may switch between branches (`material_calculator_screen.dart:13-15`).

## Displayed values

- Each cart row total is `variant.price * quantity` (`catalog_models.dart:286-301`), displayed with `toStringAsFixed(0)` and a literal `₹` prefix (`material_calculator_screen.dart:79-86`).
- Subtitle price uses `ProductVariant.priceLabel`, which calls `formatInr(price)` (`catalog_models.dart:256`). `formatInr` rounds to whole rupees and adds Western grouping for values ≥1,000; it prefixes `₹` (`catalog_models.dart:444-455`). Unit is rendered as a separate string following quantity and preceding `×`.
- `CartController.estimatedTotal == subtotal`, where subtotal is the sum of `CartItem.totalPrice` (`cart_controller.dart:41-43`). It is not the checkout grand total and does not include coupon discount, shipping, or GST (`cart_controller.dart:47-67`).
- The estimated-total display also rounds via `toStringAsFixed(0)` with a literal `₹` prefix (`material_calculator_screen.dart:94-100`).
- Items display in `cart.items` iteration order (`material_calculator_screen.dart:63-87`; controller returns an unmodifiable view of its list at `cart_controller.dart:32`).

## Style with meaning

- Item and total prices use primary-color emphasis; this is emphasis only, not a status encoding (`material_calculator_screen.dart:79-100`).

## Risk notes

- Preserve the empty/non-empty branch condition and ensure `Open Cart` remains available only in the empty branch and `Generate Quotation` only in the non-empty branch.
- Each displayed cart item is a `Card` containing a `ListTile`; these rows have no per-item handlers. Adding controls or changing cart behavior would exceed a visual-only redesign.
- Keep the `Estimated Total` tied to `cart.estimatedTotal` (item subtotal), not `grandTotal`; the label must not imply tax/shipping/coupon-inclusive checkout total.
- `Generate Quotation` currently only navigates to quotation review. Do not add calculation or submission behavior under this visual contract.
